# 저출산·고령화에 따른 혈액 수급 불균형 대응 (산업공학 졸업프로젝트 2조)

헌혈하는 사람은 줄고 수혈받는 고령층은 늘어날 때, 혈액이 언제·얼마나 부족해지는지 예측하고
대응 정책을 찾는 프로젝트다.

## 연구 구조 (3단계)

| 단계 | 질문 | 방법 | 주로 쓰는 데이터 번호 |
|---|---|---|---|
| **L1** 수급 전망 (연 단위) | 인구가 늙고 줄면 2040년까지 헌혈 공급과 수혈 수요는 어떻게 될까? | 코호트 회계모형 + 몬테카를로 | 05, 06, 07, 09, 12, 13, 14, 15, 02 |
| **L2** 결핍 예측 (일 단위) | 언제 적혈구 재고가 부족해질까? 7·14일 전에 알 수 있을까? | 분위수 회귀 (SARIMAX, LightGBM) | 03, 10 (+ 기상·공휴일) |
| **L3** 배분 최적화 (운영) | 부족이 예측되면 어떻게 배분해야 할까? | 롤링 호라이즌 MILP | L1·L2 결과 |

자세한 연구 설계와 가정은 [docs/proposal.md](docs/proposal.md)에 있다.

## 바로 실행하기

VS Code에서 이 폴더를 열고 아래 중 하나를 하면 된다.

- **F5** (또는 왼쪽 "실행 및 디버그" → `분석 보고서 만들기 (그래프 + HTML)`)
- **Ctrl+Shift+B** (빌드 작업 `분석 보고서 만들기`)
- 터미널: `py src/make_report.py`

실행하면 원본 → 가공 테이블 → 그래프 → 보고서까지 한 번에 다시 만들고, 끝나면 브라우저로 보고서를 연다.

| 결과 | 내용 |
|---|---|
| `reports/report.html` | 그래프와 "쉽게 말하면" 설명이 들어간 보고서. 파일 하나라 그대로 공유 가능 |
| `reports/figures/*.png` | 그래프 7개. 발표 자료에 그대로 붙여 넣기용 |
| `data/processed/*.csv` | 분석용 가공 테이블 |

보고서의 숫자와 문장은 모두 원본에서 계산되므로, `data/raw/`의 파일을 새로 받아 넣고 다시 실행하면 전부 갱신된다.

필요한 패키지: `pandas`, `matplotlib` (그래프 한글 글꼴은 윈도우 기본 "맑은 고딕").
