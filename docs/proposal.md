# 저출산·고령화에 따른 혈액 수급 불균형 대응 (산업공학 졸업프로젝트, 2조)

## 연구 구조 (3계층)

| 계층 | 질문 | 방법 | 입력 | 출력 |
|---|---|---|---|---|
| L1. 수급 전망 (연) | 인구구조 변화가 혈액 수급을 어디로 이끄는가 | 코호트 회계모형 + 몬테카를로 | 연령별 헌혈률·수혈률, 장래인구추계 | 수급 적자 전환 시점, 정책 시나리오별 효과 (헌혈 상한연령 조정 등) |
| L2. 결핍 예측 (일) | 언제, 어느 제제에 결핍이 발생하는가 | 분위수 회귀 (기준 SARIMAX, 주 LightGBM) | 일별 재고, 달력(요일·공휴일·방학), 기상 | 제제별 7·14일 선행 P(보유일수 < 5일) |
| L3. 배분 최적화 (운영) | 예측에 근거해 무엇을 해야 하는가 | 롤링 호라이즌 MILP (확장: MDP → 강화학습) | L1 시나리오 파라미터, L2 결핍확률, 당일 실재고 | 제제 간 대체·배분·재배분 정책, FIFO 대비 개선율 |

## 핵심 정의

- 일 소요량 = 연간 공급실적 ÷ 365 (윤년 366)
- 보유일수 = 재고 ÷ 일 소요량
- 결핍 기준: 적혈구제제 보유일수 5일 미만 (관심 단계)

## 데이터 확인 결과 (2026-10-01)

1. **KOSIS "수혈용 혈액 보유 추이(일별)"는 총량이 아니라 농축적혈구 재고다.** 월평균이 "월평균 보유 추이"의 농축적혈구와 2006~2025 전 월에서 일치한다.
   → 적혈구는 실측 일별 시계열(2005~2025)을 그대로 쓴다. 비례배분이 필요 없다.
   → 혈소판·혈장은 일별 자료가 없고 월평균만 있다. L2의 제제별 일 단위 예측은 적혈구에 한정하고, 나머지는 월 단위로 다룬다.
2. **적혈구 소요량은 적혈구 계열 3종(농축·세척·백혈구여과제거)의 공급 합 ÷ 365로 정의한다.** 2025년은 5,030/일로, 공표치 5,052/일과 0.4% 차이다.
   농축적혈구만 쓰면 3,711/일이 되어 27% 과소추정된다.
3. **원자료 오류.** 일별 표의 2005년 02/29~12/31(307일)이 2016년 값과 동일하다. 해당 구간을 제외한다.

## 방법론상 가정 및 한계 (누적 기록)

1. 재고는 농축적혈구만 포함하지만, 소요량은 백혈구여과제거·세척적혈구를 포함한다. 분자와 분모의 범위가 다르다. 공표 보유일수와 같은 정의인지 확인이 필요하다.
2. **"5일 미만" 기준은 결핍 이벤트로 쓰기에 너무 흔하다.** 2019~2021년에는 연중 94~96%의 날이 5일 미만이었다. 분류 타깃으로 변별력이 없으므로 L2 타깃 기준은 3일 미만(주의 단계) 등으로 재검토한다.
